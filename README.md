# rubiks-cube-solver

See [BRANCHES.md](BRANCHES.md) for the deployable variants (`cpp`, `js`, `ui-threejs`).

## Origins

The C++ base is forked from [LakshyaMittal3301/rubiks-cube-solver](https://github.com/LakshyaMittal3301/rubiks-cube-solver) by Lakshya Mittal and Shubham Patil: the three cube representations, the DFS/BFS/IDDFS solvers, `PermutationIndexer`, `NibbleArray` and the corner pattern database. Built on top here: the edge pattern databases, recursive IDA*, cube validation, the solver API and server, and the web app.
